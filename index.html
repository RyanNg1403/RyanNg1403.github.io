Current project TypeScript · open source

uit-cli

A terminal-first course workspace for UIT Moodle. Sign in, browse courses and materials, track deadlines, download files, inspect grades, and submit work in a workflow that stays close to the terminal.

View repository ↗ Read the README ↗
Problem
Coursework scattered across too many clicks
Shape
CLI + local course workspace
Why it matters
A small tool built for real daily friction
uit — daily workflow ready

$ uit courses --current

# see the courses that matter now

$ uit contents <course_id>

# browse modules, folders, and files

$ uit deadlines

# surface assignment IDs and due dates

$ uit submit <assign_id> <file>

# finish the loop when it is ready

From course ID to submitted work, with less context switching.
